# 每日折扣模型排名检查

读取最新的排名数据（`data/daily_ranking.log` 的最后一行），分析并发送通知。

## 分析规则

1. **数据源**: `data/daily_ranking.log`，每行是一个 JSON 对象，包含时间戳和结果
2. **比较基准**: 倒数第二行 vs 最后一行
3. **模型分类**:
   - **新模型**: 上次日志中 Top 30 没有、这次新出现的模型
   - **已有模型**: 上次日志中已存在的模型

## 通知格式

**每天必须发送通知**，无条件。

使用飞书卡片 2.0 格式，发送到群聊 `oc_3be685570d8132424cb03e8d831a4f9b`，以 bot 身份发送。

卡片结构：
1. Header: "📊 OpenRouter 折扣模型每日更新"，蓝色模板，日期副标题
2. 3个指标卡（水平排列）:
   - 总模型数（蓝色背景）
   - 有折扣模型数（绿色背景）
   - AA 匹配数（橙色背景）
3. 🆕 新模型表格（仅当有新模型时显示）:
   - 列: #, 模型名称, 厂商, 智能指数, 输入价格, 输出价格, 最高折扣, 折扣供应商
4. 📋 已有模型表格:
   - 列: #, 模型名称, 厂商, 智能指数, 输入价格, 输出价格, 最高折扣, 折扣供应商
5. 变化摘要
6. 数据来源说明（灰色小字）: "数据来源：OpenRouter API + Artificial Analysis · 价格单位：美元/百万Token"

## 发送命令

```bash
lark-cli im +messages-send \
  --chat-id oc_3be685570d8132424cb03e8d831a4f9b \
  --msg-type interactive \
  --content '<卡片JSON>' \
  --as bot
```

## 无变化时

仍然发送通知，变化摘要注明"无变化"即可。
